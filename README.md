# 🎮 Open Source Minecraft Launcher

Un launcher de Minecraft **open source**, desarrollado para ser personalizable y fácil de compilar.

## 📦 Requisitos

Antes de comenzar, necesitas tener **Node.js** instalado en tu computadora.

Descarga la versión requerida aquí:

👉 https://nodejs.org/dist/v24.17.0/node-v24.17.0-x64.msi

---

## 🚀 Instalación y ejecución

### 1. Descargar el proyecto

Puedes descargar este proyecto de dos formas:

* Descargar el repositorio como **ZIP**
* Clonarlo usando **GitHub Desktop** o Git

---

### 2. Instalar dependencias

Una vez descargado el proyecto:

1. Abre la carpeta del proyecto.
2. Ubícate donde se encuentra el archivo `package.json`.
3. Abre una terminal dentro de esa carpeta.
4. Ejecuta el siguiente comando:

```bash
npm install
```

Esto descargará e instalará todas las dependencias necesarias.

---

### 3. Ejecutar el launcher

Cuando termine la instalación, ejecuta:

```bash
npm start
```

Esto iniciará la aplicación en modo desarrollo.

---

## 🛠️ Compilar y generar el `.exe`

Para compilar el proyecto y generar el ejecutable:

```bash
npm run build
```

Al finalizar el proceso encontrarás el archivo `.exe` generado dentro de la carpeta de salida correspondiente.
